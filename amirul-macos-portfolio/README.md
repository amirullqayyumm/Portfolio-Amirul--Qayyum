# Amirul Qayyum — macOS-inspired Portfolio

A responsive React/Vite portfolio with Finder-inspired navigation, desktop wallpaper, a working dock, theme switching, and content based on Amirul Qayyum's résumé. The only listed project is HR Management System.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown by Vite (usually http://localhost:5173).

## Project files

- `src/App.jsx`: all content, navigation, and interactions
- `src/App.css`: complete responsive macOS-inspired design
- `src/index.css`: global styles
- `src/main.jsx`: React entry point
- `index.html`: browser metadata

## Personalize

Edit `EMAIL`, `GITHUB`, and `HRMS` in `src/App.jsx` if needed. The HRMS GitHub repo is currently private; visitors need permission until it's made public.

This portfolio intentionally does **not** publicly link the original résumé PDF because it contains personal and referee contact information. Share a redacted/public version if you later add a resume download button.
